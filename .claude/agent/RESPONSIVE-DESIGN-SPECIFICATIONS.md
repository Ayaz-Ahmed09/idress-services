Tailwind Breakpoints:
- Mobile first (default): < 640px
- sm: 640px+
- md: 768px+
- lg: 1024px+
- xl: 1280px+
- 2xl: 1536px+

CRITICAL RESPONSIVE RULES:
1. All text readable without zooming on mobile
2. Touch targets minimum 44x44px
3. No horizontal scroll on any viewport
4. Forms fill full width on mobile
5. CTA buttons stack vertically on mobile
6. Sub-service cards: 1 column mobile, 2 tablet, 3-4 desktop
7. Navigation: Full menu desktop, hamburger mobile
8. Floating CTA: Bottom bar on mobile, floating buttons on desktop
9. Font sizes scale down appropriately
10. Spacing reduces on mobile (padding, margins)
